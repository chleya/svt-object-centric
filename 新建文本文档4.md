========================
四、新增模型 1：MLP Position-Only
========================

文件：

models/mlp_position_only.py

模型名称：

MLPPositionOnly

输入：
observed_positions: [B, t_obs, N, 2]

输出：
pred_future_positions: [B, t_pred, N, 2]

结构要求：
- 简单 MLP
- 不使用 feature
- 不使用 identity label
- 输入 flatten 后送入 MLP
- 输出 reshape 成 future positions

建议结构：
input_dim = t_obs * num_objects * 2
hidden_dim = 256
layers = 3 或 4
activation = ReLU
dropout 可选，默认 0.0 或 0.1
output_dim = t_pred * num_objects * 2

训练目标：
MSE(pred_future_positions, future_positions)

用途：
检查普通函数拟合是否只学到轨迹预测，而没有身份结构。

预期：
- clean_skill 可能中等
- identity_swap_only 可能较低
- OOD skill 可能下降

========================
五、新增模型 2：MLP Position + Feature
========================

文件：

models/mlp_position_feature.py

模型名称：

MLPPositionFeature

输入：
observed_positions: [B, t_obs, N, 2]
observed_features: [B, t_obs, N, F]

输出：
pred_future_positions: [B, t_pred, N, 2]
identity_logits 或 identity_prediction

最低要求：
- 必须使用 observed_features
- 必须有 trajectory prediction head
- 必须有 identity head，用于预测是否 swap 或预测 future-object to observed-object assignment

建议输入：
concat observed_positions 和 observed_features 后 flatten。

trajectory head：
输出 future positions。

identity head：
对于 N=2，可以输出一个 swap_logit：
- 0 表示 no-swap
- 1 表示 swap

或者输出 [B, N, N] assignment logits。
如果实现复杂，先用 swap_logit。

训练损失：
loss = mse_loss + identity_weight * identity_loss

建议：
identity_weight = 1.0
identity_loss = BCEWithLogitsLoss for swap/no-swap

注意：
- identity supervision 只能用于训练 learned identity head；
- evaluation 必须使用 identity_swap_only；
- 不要用 identity_overall 做主结论。

用途：
检查显式 feature 是否能帮助 learned model 做身份追踪。

预期：
- identity_swap_only 应高于 MLPPositionOnly
- 如果没有提高，说明 feature 没被模型利用，或者 identity head / label 处理有 bug。

========================
六、新增模型 3：Object-Centric Feature Model
========================

文件：

models/object_centric_feature.py

模型名称：

ObjectCentricFeatureModel

目标：
实现最小 object-file inductive bias。

输入：
observed_positions: [B, t_obs, N, 2]
observed_features: [B, t_obs, N, F]

结构：
1. 对每个 object slot 单独编码：
   obj_input_i = concat(position_i over time, feature_i over time)
2. 使用共享 per-object encoder：
   MLP 或 GRU 均可
3. 每个 object 得到一个 object embedding
4. trajectory head:
   每个 object embedding 预测该 object 的 future trajectory
5. identity head:
   根据 object embeddings 预测 swap/no-swap 或 assignment

最低实现：
- 共享 MLP per object encoder
- 不强制实现复杂 attention
- 不实现 Slot Attention
- 不实现 Transformer

训练损失：
loss = future_mse + identity_weight * identity_loss

用途：
测试 object-centric inductive bias 是否比普通 MLP 更有利于 identity_swap_only。

预期：
- identity_swap_only 应高于 MLPPositionOnly
- 可能高于 MLPPositionFeature
- OOD prediction 未必高
