========================
二、数据生成修复要求
========================

请实现或修改数据生成器，支持以下参数：

generate_dataset_v22(
    n_episodes: int,
    t_obs: int,
    t_pred: int,
    num_objects: int = 2,
    arena_size: float = 64.0,
    feature_mode: str = "featureless" | "feature_bearing",
    randomize_object_order: bool = True,
    independent_train_test_order: bool = True,
    disjoint_init_split: bool = True,
    identity_test: bool = True,
    swap_probability: float = 0.5,
    seed: int = 0,
)

核心要求：

1. randomize_object_order=True 必须成为默认值。
   - 每个 episode 生成后，随机打乱 object 维度顺序；
   - observed_positions、future_positions、features、identity labels 必须同步更新；
   - train/test 的 object order 随机化必须相互独立；
   - 不允许 train/test 共享固定 object 0/object 1 编号语义。

2. feature_mode="featureless"
   - 两个物体没有可观测身份特征；
   - same color / same radius / no marker；
   - 这是不可辨识对照；
   - FeatureAwareIdentityBaseline 应接近 0.5。

3. feature_mode="feature_bearing"
   - 每个物体有唯一可观测特征；
   - 最简单实现：
     object_features shape = [episodes, timesteps, num_objects, feature_dim]
     object 0 feature = [1, 0]
     object 1 feature = [0, 1]
   - feature 必须在 observed 和 future 中都存在；
   - 如果发生 swap，feature 应跟随“真实身份”而不是当前位置；
   - FeatureAwareIdentityBaseline 应接近 1.0。

4. identity labels
   - 必须清晰定义：
     identity label 表示未来 object slot 与观察阶段真实 identity 的对应关系；
   - 如果发生 object order randomization，identity labels 必须同步变换；
   - 如果发生 swap，labels 必须反映真实身份，而不是当前 slot 位置；
   - 请在 README 中明确写出 identity label 的定义。

5. disjoint_init_split=True
   - 默认启用 train/test 初始位置分区；
   - train/test 初始位置 bins 尽量不重叠；
   - 如果实现困难，至少实现一个 left/right 或 grid split；
   - 输出 mean_initial_position_gap 用于健康检查。

6. 保留原 v2 featureless 任务作为对照，但必须标记为：
   "featureless_not_identifiable_control"

========================
三、FeatureAwareIdentityBaseline
========================

请新增：

baselines/feature_aware_baseline.py

实现 FeatureAwareIdentityBaseline。

目标：
- 在 feature_bearing 数据上，通过 object_features 直接匹配 identity；
- 在 featureless 数据上退化为随机或无法判断。

接口建议：

class FeatureAwareIdentityBaseline:
    def predict_identity(self, observed_features, future_features):
        ...
    def score(self, observed_features, future_features, identity_labels):
        ...

逻辑：
1. 对每个 future object，找与 observed object feature 最相似的 identity；
2. 对 feature_bearing:
   - one-hot feature 应能稳定匹配；
   - identity_accuracy 应接近 1.0；
3. 对 featureless:
   - 没有 feature 信息；
   - identity_accuracy 应接近 0.5；
4. 如果 feature 输入不存在或全零，明确返回 random baseline，并在 notes 中说明。

输出：
results/svt_v2_2_dataset_fix/feature_identity_baseline.csv

字段：
seed
feature_mode
identity_accuracy
expected
status
notes

通过标准：
- featureless: 0.4 <= accuracy <= 0.6
- feature_bearing: accuracy >= 0.95

如果不满足，打印：
"Feature identity health check failed."
