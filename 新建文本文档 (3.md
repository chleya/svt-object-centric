========================
三、非线性动力学环境
========================

实现 envs/nonlinear_force_world.py。

环境要求：
- 2D arena，默认 64x64；
- num_objects=2；
- object_radius 可配置；
- t_obs 默认 10；
- t_pred 默认 20；
- 支持 feature_bearing objects；
- 支持 featureless control；
- 支持 occlusion；
- 支持 crossing trajectories；
- 支持 swap/no-swap split；
- 支持 randomized object order；
- 支持 disjoint train/test initialization；
- 支持 OOD force transfer。

动力学更新：

a_t = force_field(x_t, v_t, params)
v_{t+1} = damping * v_t + a_t * dt + noise
x_{t+1} = x_t + v_{t+1} * dt

必须至少支持以下 force_field_type：

1. attractor
   - 向一个中心点吸引；
   - a = strength * normalize(center - x) / distance_factor

2. repulsor
   - 从中心点排斥；
   - a = strength * normalize(x - center) / distance_factor

3. vortex
   - 围绕中心旋转；
   - a 垂直于 center->x 方向；
   - 用于打破 simple velocity extrapolation

4. gravity_well
   - 类似 attractor，但随距离变化更强；
   - 可用 inverse-square 或 softened inverse-square

可选：
5. piecewise_field
   - 不同区域使用不同 field；
   - 如果实现复杂，可跳过。

必须配置：
- field_strength
- field_center
- damping
- noise_std
- dt
- boundary_mode: "bounce" 或 "toroidal"

注意：
- v3 主要目的是让 LastVelocityBaseline 失效；
- 不要让动力学过难到所有模型都接近随机；
- 需要输出 LastVelocityBaseline 的 skill 作为 sanity check。

========================
四、数据生成器
========================

实现 data/generate_nonlinear_feature_ood.py。

主函数建议：

generate_v3_dataset(
    n_train=1000,
    n_test=200,
    t_obs=10,
    t_pred=20,
    feature_mode="feature_bearing" | "featureless",
    force_train_type="attractor",
    force_test_type="vortex",
    force_train_params=None,
    force_test_params=None,
    randomize_object_order=True,
    disjoint_init_split=True,
    allow_occlusion=True,
    allow_crossing=True,
    swap_probability=0.5,
    seed=0,
)

必须生成以下 split：

1. train_id
   - feature_bearing
   - force_train_type
   - randomized object order
   - normal mixed swap/no-swap

2. clean_test_id
   - 与 train 同分布
   - 用于 clean_skill

3. identity_test_mixed
   - swap_probability=0.5
   - 只用于诊断，不作为主身份指标

4. identity_test_swap_only
   - swap_probability=1.0
   - 必须保证 100% swap
   - 主 identity 指标使用这个 split

5. identity_test_no_swap_only
   - swap_probability=0.0
   - 必须保证 0% swap
   - 用于 no-swap bias 诊断

6. crossing_occlusion_test
   - 强制 crossing + occlusion
   - 至少一段 temporary occlusion
   - 尽量让两个 objects 轨迹交叉

7. ood_force_test
   - force_test_type 与 train 不同，或 force_strength/damping/noise 参数不同
   - 用于 OOD transfer

8. featureless_control_test
   - featureless objects
   - 用于不可辨识对照
   - 不作为模型失败主证据

数据字段建议：

observed_positions: [B, t_obs, N, 2]
future_positions: [B, t_pred, N, 2]
observed_features: [B, t_obs, N, feature_dim] or None
future_features: [B, t_pred, N, feature_dim] or None
identity_labels: [B, N]
is_swap: [B]
has_occlusion: [B]
has_crossing: [B]
force_type: str or array
force_params: dict or serialized JSON
metadata: dict

重要：
- feature 必须跟随真实 identity；
- object order randomization 必须同步更新 positions、features、identity_labels；
- swap-only split 必须真的 100% swap；
- no-swap-only split 必须真的 0% swap；
- 如果无法保证，脚本必须 fail fast，而不是继续跑。

========================
五、模型与 baseline
========================

v3 最少评估以下模型：

1. LastVelocityBaseline
   - 线性速度外推；
   - 目标是证明 nonlinear dynamics 使它不再饱和 prediction。

2. RawTrajectoryKNN v1
   - 复用已有。

3. RawDeltaKNN v2
   - 复用已有；
   - 检查 Delta-Output Identity Paradox 是否仍成立。

4. TranslationNormalizedKNN
   - 检查绝对位置 shortcut。

5. FeatureAwareIdentityBaseline
   - 不预测动力学；
   - 只用于 identity upper-bound；
   - 在 feature_bearing swap-only 应接近 1.0；
   - 在 featureless 应接近 0.5。

6. RandomIdentityBaseline
   - identity 随机；
   - 应接近 0.5。

7. SimpleMLPPredictor
   - 如果已有 MLP predictor，复用；
   - 如果没有，可跳过但 README 说明。

8. ObjectCentric or SlotPersistence
   - 二选一即可；
   - 如果已有则复用；
   - 不要为了 v3 重写复杂训练框架。

9. OracleDynamics
   - 如果已有 physics oracle，扩展支持 nonlinear force；
   - 如果没有，至少实现 feature-aware identity oracle 和 force oracle baseline；
   - Oracle 用于证明任务可解，不参与普通模型比较。

注意：
- 如果 learned models 训练成本太高，第一版 v3 可以只跑 baselines + oracle；
- 但 README 必须标明 learned models not yet evaluated。

5. No-swap bias
   - no_swap_bias_gap = identity_overall - identity_swap_only
   - no_swap_bias_flag = gap > 0.1

6. Gated SVTScore v3

主分数：

gated_score_swap_only =
    max(clean_skill, 0)
  * max(cf_skill, 0)
  * max(comp_skill, 0)
  * max(identity_swap_only, 0)

如果 cf_skill 或 comp_skill 当前没有明确 split，可使用：
- comp_skill = crossing_occlusion_skill
- cf_skill = ood_skill
并在 README 明确说明。

同时输出：

gated_score_overall_id =
    max(clean_skill, 0)
  * max(cf_skill, 0)
  * max(comp_skill, 0)
  * max(identity_overall, 0)

必须报告：
score_drop = gated_score_overall_id - gated_score_swap_only

解释：
如果 score_drop 很大，说明旧 overall identity 夸大了结构表现。

========================
十、README.md 要求
========================

README 必须包含：

1. Purpose
   - v3 测试非线性、feature-bearing、OOD、occlusion/crossing 下的结构有效性；
   - v3 不再修 identity pipeline，而是在健康 identity gate 上运行。

2. Health Gate Result
   - pass/fail
   - 如果 fail，明确哪些结果不能解释。

3. Why swap-only identity is primary
   - 简述 v2.4 的规则；
   - 禁止使用 overall identity 做主结论。

4. Dataset
   - nonlinear force fields
   - feature-bearing objects
   - randomized object order
   - disjoint train/test
   - swap-only/no-swap-only splits
   - OOD force transfer

5. Main Results
   - prediction
   - identity_swap_only
   - OOD transfer
   - crossing/occlusion
   - no-swap bias

6. Interpretation Rules
   - featureless random 不等于模型失败；
   - feature_bearing swap-only 失败才说明 identity tracking 不足；
   - LastVelocityBaseline 下降说明 velocity shortcut 被削弱；
   - RawKNN ID 高但 OOD 低说明检索而非结构；
   - DeltaKNN prediction 高但 identity_swap_only 低说明 Delta-Output Identity Paradox 延续。

7. Final Recommendation
   只能是以下之一：
   - proceed_to_v3_learned_models
   - fix_v3_health_gate_first
   - increase_nonlinearity
   - add_stronger_object_file_model
   - revise_metrics

不要写：
- SVT passes
- model understands objects
- identity overall proves tracking

========================
十一、最低成功标准
========================

v3 第一版最低成功不是模型高分，而是 benchmark 有区分度。

必须检查：

1. Health gate passes
2. LastVelocityBaseline clean_skill 明显低于线性环境中的表现
3. FeatureAwareIdentityBaseline feature_bearing swap-only >= 0.95
4. RandomIdentityBaseline swap-only around 0.5
5. at least one KNN model shows:
   - ID performance drops on OOD, or
   - prediction high but identity_swap_only low, or
   - strong no-swap bias
6. gated_score_swap_only differs from gated_score_overall_id when no-swap bias exists

如果这些成立，v3 benchmark 有价值。
